# PKI Anti-Patterns

## 1. Monolithic trust domain

One issuing CA for all use cases increases blast radius and weakens governance.

## 2. Certificate ownership ambiguity

Certificates without accountable owners create hidden operational risk.

## 3. Validation services as afterthought

CRL/OCSP weaknesses cause outages even when CA hierarchy is correct.

## 4. Manual renewal dependence

Manual-only renewal paths do not scale and generate avoidable incidents.

## 5. Policy without telemetry

If policy enforcement cannot be measured, governance is aspirational.

## 6. Late algorithm migration

Postponed crypto transition creates compounded technical debt.
